# 🍮 달콤 방어전 (Sweet Defense)

모바일 브라우저에서 바로 즐기는 라인 배틀 타워디펜스. "냥코대전쟁" 스타일의 조작감에,
**디저트 부대 vs 채소 군단**이라는 완전히 다른 캐릭터 컨셉을 얹었다.

설치도 빌드도 필요 없다. `index.html`을 열면 끝.

## 플레이 방법

1. 자금(🍬)은 시간이 지나면 자동으로 찬다.
2. 화면 아래 카드를 눌러 유닛을 출격시킨다. 카드마다 비용과 재사용 대기시간이 있다.
3. 유닛은 자동으로 전진해 적을 공격한다. **적 본진을 부수면 승리**, 아군 본진이 부서지면 패배.
4. 화면을 좌우로 밀어 전장을 둘러볼 수 있고, 우측 상단 버튼으로 2배속 전환이 된다.
5. 전투로 얻은 꿀(🍯)로 지갑·수급·공격력·체력·성벽을 강화한다.

## 콘텐츠

- **1번 맵 · 20 스테이지.** 앞 스테이지를 깨야 다음이 열린다. 5 / 10 / 15 / 20은 보스전.
- **아군 8종 (디저트 부대)** — 푸딩 신병, 마시멜로 방벽, 초코칩 사수, 마카롱 쌍둥이,
  슈크림 폭탄병, 도넛 롤러, 케이크 대포, 아이스크림 여왕.
  스테이지를 진행할수록 순차 해금된다.
- **적 10종 (채소 군단)** — 콩알 졸병부터 무 장군, 호박 대왕, 마늘 대군주까지.
- **메타 강화 5종**, 각 10레벨. 진행 상황은 브라우저 `localStorage`에 저장된다.

## 전투 규칙

- 유닛은 사거리 안의 가장 가까운 적을 공격한다. 적이 없으면 전진한다.
- 체력이 일정 구간씩 깎일 때마다 **넉백**되어 뒤로 밀린다(냥코식 밀고 당기기).
- 범위 공격 유닛은 착탄 지점 주변의 모든 대상에게 피해를 준다.
- 근접/원거리, 이동 속도, 재사용 대기시간의 조합으로 전선 구성이 달라진다.

## 실행

```bash
# 그냥 파일로 열기
open index.html

# 또는 로컬 서버 (PWA / 오프라인 캐시까지 확인하려면 이쪽)
python3 -m http.server 8000
```

GitHub Pages 등 https 로 배포하면 `manifest.json` + `sw.js` 덕분에 홈 화면에
설치해 오프라인으로도 플레이할 수 있다.

## 구조

```
index.html        화면 마크업 (타이틀/지도/강화/도감/전투)
css/style.css     모바일 UI 스타일
js/data.js        유닛·적·스테이지·강화 데이터 (밸런스는 전부 여기)
js/game.js        전투 엔진 (이동, 타겟팅, 넉백, 범위 피해, 승패)
js/render.js      캔버스 렌더러 (배경, 캐릭터 도형, 이펙트, 미니맵)
js/main.js        화면 전환, 저장/불러오기, 메인 루프, 입력
sw.js             오프라인 캐시
```

밸런스를 만지려면 `js/data.js`의 `UNITS`, `ENEMIES`, `STAGES`만 보면 된다.
새 스테이지는 `STAGES` 배열에 `waves` 항목을 추가하면 그대로 지도에 나타난다.
