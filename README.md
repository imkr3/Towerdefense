# ⚔️ 막대 왕국 전쟁 (Stick Kingdom War)

가로 화면 전용 중세 라인 배틀 타워디펜스. 캐릭터는 전부 **졸라맨**이고,
투구·방패·도끼·망토·로브로 병종을 구분한다. 이미지 파일은 한 장도 쓰지 않고
전부 캔버스에 선과 도형으로 그린다.

브라우저에서는 `index.html`만 열면 되고, 안드로이드는 **[릴리스에서 APK를 바로 받는다](https://github.com/imkr3/Towerdefense/releases/latest)**.

## 플레이 방법

1. 군자금은 시간이 지나면 저절로 찬다.
2. 화면 아래 카드를 눌러 병사를 출진시킨다. 카드마다 비용과 재정비 시간이 있다.
3. 병사는 알아서 전진해 싸운다. **적 요새를 무너뜨리면 승리**, 아군 성채가 무너지면 패배.
4. 화면을 좌우로 밀어 전장을 살피고, 우측 상단 버튼으로 2배속을 켠다.
5. 병영에서 군자금·무기·갑옷·성벽을 강화하고, 훈련소에서 병종 레벨을 올린다.
6. 훈련소에서 **최대 10개 병종을 편성**한다. 전투 카드는 편성한 병종만 나온다.

## 조작

| 버튼 | 기능 |
|---|---|
| 카드 | 편성한 병종 출진 (비용 + 재정비) |
| 왕의 명령 | 전군 25% 회복 + 8초간 공격 속도 상승. 재사용 대기 있음 |
| 자동 | 낼 수 있는 카드를 알아서 출진시킨다 |
| ▶▶ | 1x → 2x → 3x 배속 |
| ⏸ | 일시정지 |

## 무한 전장

20전장을 모두 돌파하면 열린다. 파도가 갈수록 촘촘하고 강해지며 5파도마다 보스가 나온다.
적 요새는 부술 수 없고, **성채가 무너질 때까지 몇 파도를 버텼는지**가 기록으로 남는다.
파도당 골드와 5파도당 소환석을 준다.

## 임무 · 업적 · 기록

- **일일 임무** 매일 3개가 새로 뽑힌다. 처치, 승리, 별 3개 승리, 소환, 왕명 사용,
  훈련, 보스 처치, 무한 파도 등 10종에서 날짜별로 고정 선택된다. 골드와 소환석을 준다.
- **업적 15종** 전장 돌파, 별 수집, 누적 처치, 소환 횟수, 전설 보유, 무한 기록 등.
  조건을 만족하면 즉시 보상이 들어온다.
- **기록** 치른 전투, 승리, 누적 처치, 보스 처치, 소환 횟수, 총 전투 시간을 모아 본다.

## 자동 출진

전투 중 `자동` 버튼을 켜면 낼 수 있는 카드 중 비싼 것부터 알아서 내보낸다.
반복 전투나 무한 전장에서 편하다.

## 소환의 제단 (뽑기)

전장 밖에서 얻는 두 번째 성장 축이다. **소환석**으로 신화 병종을 뽑는다.

- 소환석은 전장을 처음 돌파할 때 2개, 별을 새로 딸 때마다 1개씩 들어온다.
  급하면 골드 2000으로 하나 살 수 있다.
- 1회 소환은 소환석 1개, 10회 소환은 9개다. 10회에는 **영웅 이상 1개가 확정**으로 나온다.
- 등급은 일반 52% · 희귀 30% · 영웅 14% · 전설 4%. **40회 안에 전설이 확정**으로 나온다.
- 이미 가진 병종이 또 나오면 그 병종의 **레벨이 1 올라가고** 등급에 따라 골드를 돌려받는다.
- 뽑은 병종은 훈련소에서 레벨을 올리고 편성에 넣을 수 있다. 전장 진행과 무관하게 바로 쓴다.

소환 병종은 **지름길이 아니라 다른 길**이다. 코스트당 화력은 전장 병종과 비슷하거나
조금 낮게 맞춰져 있고, 전설일수록 재정비가 길어(55~60초) 한 판에 몇 번 못 쓴다.
값은 번개 광역·일직선 관통·소환·보호막 같은 **특색**에서 나온다. 전설을 뽑았다고
전장을 건너뛸 수는 없고, 실제로 `npm run balance`가 소환 편성과 전장 편성의
클리어 수 차이를 ±4 전장 안으로 묶어 두고 검사한다.

## 시즌 (신화 배너 3종)

배너는 언제든 바꿔서 뽑을 수 있다. 픽업 시즌이 80%, 나머지 시즌이 20%로 나온다.

| 시즌 | 전설 | 영웅 | 희귀 · 일반 |
|---|---|---|---|
| **올림포스** (그리스) | 제우스 | 아레스, 아르테미스 | 메두사, 스파르타 전사, 아테네 창병 |
| **라그나로크** (북유럽) | 토르 | 발키리, 펜리르 | 바이킹 전사, 룬 주술사, 북방 궁수 |
| **나일의 왕가** (이집트) | 아누비스 | 라의 사제, 파라오 근위대 | 황금 스카라베, 사막 궁수 |

대표 능력은 이렇다.

| 병종 | 능력 |
|---|---|
| 제우스 | 사거리 380의 번개 광역, 35% 확률 기절 |
| 토르 | 광역 망치, 40% 기절에 밀쳐내기까지 |
| 아누비스 | 광역 공격 + 7초마다 미라 2기 소환 |
| 아르테미스 | 일직선 관통을 초당 1회 이상 연사 |
| 펜리르 | 이동 속도 130의 초고속 돌진 + 흡혈 40% |
| 메두사 | 50% 확률 석화(기절)와 둔화를 함께 건다 |
| 발키리 | 쓰러져도 1회 부활하며 주변을 회복 |

## 병종 (왕국군 22종 + 소환 18종)

기본 병종 외에 능력이 붙은 병종들이 있다.

| 병종 | 능력 |
|---|---|
| 사제 | 싸우지 않는 대신 2.4초마다 주변 아군 회복 |
| 독침 궁수 | 명중한 적을 5초간 중독. 체력 큰 적일수록 잘 듣는다 |
| 종군 상인 | 제자리에 고정. 살아 있는 동안 군자금이 계속 들어온다 |
| 서리 마도사 | 범위 공격 + 2.5초 둔화. 적의 이동과 공격 속도를 함께 늦춘다 |
| 결투가 | 30% 확률 치명타 2.6배, 준 피해의 35%를 회복 |
| 석궁 저격수 | 사거리 520의 일직선 관통. 줄 선 적을 한 발로 전부 꿰뚫는다 |
| 대마법사 | 광역 폭발, 20% 확률로 기절 |
| 강철 거인 | 넉백 면역. 6초마다 주변 아군에게 보호막 280 |
| 사령술사 | 6초마다 해골 병사 2기를 공짜로 소환 |
| 나팔수 | 주변 아군의 공격 속도를 30% 끌어올린다 |
| 대궁병 | 사거리 400. 전선 한참 뒤에서 안전하게 쏜다 |
| 불꽃술사 | 범위 화염 + 4초 화상 |
| 성기사 | 쓰러져도 1회 부활, 주변 아군 회복 |
| 공병 | 9초마다 나무 방벽을 세운다. 방벽은 맞아주기만 한다 |
| 쌍검 도적 | 초당 세 번 찌른다. 치명타와 흡혈 |

나머지는 창병, 방패병, 궁수, 광전사, 화약병, 기사, 투석기다.

## 적 (오크 군단 26종)

고블린 졸개, 오크 창병, 오우거, 늑대 기수, 석궁 사수, 화약통 고블린, 흑기사에 더해

- **독거미** 중독 공격 + 매우 빠름
- **오크 주술사** 주변 오크를 계속 회복시킨다. 먼저 끊어야 한다
- **방패 오크** 넉백 면역 탱커. 밀어낼 수 없다
- **망령** 죽을 때 주변을 폭발시킨다
- **오크 광전사** 체력이 깎일수록 더 빨리 때린다
- **흡혈박쥐** 매우 빠르고 때린 만큼 회복한다
- **돌 골렘** 넉백 면역에 밀쳐내기까지 한다
- **저주 토템** 제자리에 박혀 주변 오크를 가속시킨다
- **오크 투석기** 사거리 430의 공성 병기. 뒷줄까지 때린다
- **오크 사령관** 주변 오크를 가속시키며 직접 도끼를 휘두른다
- **역병 술사** 범위 중독. 오래 붙어 있으면 전선이 녹는다
- **지옥견** 이동 속도 115에 화상 공격
- **파성추** 체력 9500에 넉백 면역, 받는 피해 35% 감소
- 보스: **트롤 대장**, **리치**(고블린 소환), **서리 거인**(광역 둔화),
  **화룡**(광역 화염), **거미 여왕**(거미 소환 + 중독),
  **오크 대군주**(광역 + 밀쳐내기 + 오크 창병 소환)

적 일부는 **갑주**를 둘러 받는 피해가 줄어든다. 방패 오크 20%, 돌 골렘 25%,
파성추 35%, 오크 대군주 20%다. 물량보다 한 방이 굵은 병종이 잘 듣는다.

## 보스 패턴

보스는 그냥 큰 적이 아니다. 체력이 깎일 때마다 **페이즈**가 넘어가며 기술을 쓰고,
전투 내내 일정 주기로 **고유 기술**을 반복한다. 기술이 터질 때는 화면 위쪽에
이름이 뜬다.

| 보스 | 상시 기술 | 페이즈 (체력 기준) |
|---|---|---|
| 트롤 대장 | 바위 투척 (12초) | 65% 대지 포효 → 35% 피의 격노 → 15% 트롤의 재생 |
| 리치 | 망자 소환 (9초) | 60% 생명 흡수 → 30% 영혼 보호막 → 15% 죽음의 군세 |
| 서리 거인 | 한파 (10초) | 65% 얼음 포효 → 35% 빙하 낙하 → 15% 서리의 분노 |
| 화룡 | 화염 브레스 (9초) | 60% 분노의 불길 → 35% 용의 포효 → 15% 멸화 |
| 거미 여왕 | 알주머니 (8초) | 65% 독액 분사 → 35% 거미 떼 → 15% 여왕의 광란 |
| 오크 대군주 | 대군주의 일격 (11초) | 75% 친위대 소집 → 50% 전장의 포효 → 30% 대군주의 분노 → 12% 최후의 군세 |

기술 종류는 이렇게 돈다.

- **포효** 주변 아군을 밀어내고 기절시킨다
- **광폭화** 공격력·속도가 영구히 올라가고 몸에 붉은 기운이 감돈다
- **증원** 부하를 그 자리에 불러낸다
- **보호막 / 재생** 자기 체력을 되돌린다. 화력을 몰아 끊어야 한다
- **한파** 광역 둔화
- **생명 흡수** 주변 피해를 빨아 자기 체력으로 돌린다
- **낙하 공격** (바위 투척·빙하 낙하·화염 브레스·독액 분사·대군주의 일격)
  땅에 붉은 원이 먼저 깜박인다. 떨어지기 전에 그 자리를 비우면 맞지 않는다

## 전투 규칙

- 병사는 사거리 안의 가장 가까운 적을 친다. 적이 없으면 전진한다.
- 체력이 일정 구간씩 깎일 때마다 **넉백**되어 뒤로 밀린다. 넉백 면역 병종은 예외.
- 상태이상: 중독·화상(지속 피해), 둔화(이동·공격 속도 45%/170%), 기절(행동 불가),
  가속(공격 속도 상승), 보호막(피해 흡수), 갑주(받는 피해 감소).
- **적은 무한이다.** 대본에 적힌 파도를 다 막아도 적 요새는 병력을 계속 내보낸다.
  증원은 갈수록 간격이 좁아지고 한 마리 한 마리가 세진다(최대 2.2배).
  버티기만 해서는 절대 끝나지 않으니, 결국 요새를 부수러 나가야 한다.
- 증원이 돌기 시작하면 상단의 남은 적 수가 **∞** 로 바뀐다.
- 증원 부대에는 보스·갑주·넉백 면역·장거리 공성이 섞이지 않는다. 그것들이 끝없이
  흘러나오면 뚫을 수 없는 벽이 되어 전선이 영영 멈추기 때문이다.
  대신 여섯 번에 한 번은 그런 중장 병력이 딸려 온다.
- 전장에 동시에 설 수 있는 적은 24기까지다. 숫자가 아니라 강함으로 조여 온다.
- 전투가 60초를 넘기면 자금이 차는 속도가 서서히 올라 최대 2.4배가 된다.
  적의 증원과 맞물리는 장치라, 늘어지는 싸움일수록 보급 회전이 승부를 가른다.
- 범위 공격은 착탄 지점 주변 전부를, 관통은 사수와 착탄점 사이 전부를 때린다.

## 성장과 난이도

- **병종 레벨**: 레벨당 체력·공격력 +10%, 최대 15레벨.
  상한은 `5 + 돌파한 전장 수`라서 진도 없이 한 병종만 키울 수는 없다.
- **병영 강화 10종**: 군자금 금고, 세금 징수, 무기 연마, 갑옷 강화, 성벽 보수,
  병참(재정비 단축), 전시 국고(시작 자금), 전리품 수거(처치 골드),
  사관학교(레벨 상한 +1), 왕의 명령(재사용 단축·회복량).
- **별 평가**: 성채를 얼마나 지켰는지로 전장마다 별 1~3개. 처음 딴 별은 골드와 소환석을 준다.
- **소환**: 신화 시즌 병종 18종. 뽑기와 중복 레벨업으로 따로 성장한다.
- 20개 전장 전부 시뮬레이션으로 확인한 곡선은 이렇다.

| 성장 수준 | 클리어 |
|---|---|
| 강화 0 / 병종 Lv1 | 3전장 부근에서 막힌다 |
| 강화 2 / 병종 Lv3 | 12전장 |
| 강화 3 / 병종 Lv5 | 14전장 |
| 강화 5 / 병종 Lv8 | 20전장 전부 |

한 판은 60초에서 300초 사이다. 후반 전장은 적이 거센 만큼 보급(자금 회복)도 빠르다.
강화 없이 밀고 나가는 건 3전장까지다. 그 뒤로는 병영을 올려야 한다.

## APK 만들기

`android/`에 WebView 래퍼 안드로이드 프로젝트가 들어 있다. 게임 파일은 빌드할 때
`syncWebAssets` 태스크가 저장소 루트에서 `app/src/main/assets/www`로 복사하므로,
웹 버전과 APK가 항상 같은 코드로 돌아간다.

**이미 만들어진 APK 받기 (가장 쉬움)**

[릴리스 페이지](https://github.com/imkr3/Towerdefense/releases/latest)에서
`stick-kingdom-war-<버전>.apk` 를 내려받아 설치한다. 로그인도 필요 없다.

**새 버전 릴리스하기**

Actions 탭에서 `Android APK` 워크플로를 수동 실행하면서 `릴리스로 배포할 버전`에
`1.2.0` 처럼 적으면, 빌드가 끝난 뒤 태그와 릴리스가 만들어지고 APK가 첨부된다.
`v` 로 시작하는 태그를 푸시해도 같은 일이 일어난다.

**GitHub Actions 아티팩트로 받기**

`.github/workflows/android.yml`이 디버그와 릴리스 APK를 모두 만들어
`stick-kingdom-war-apk` 아티팩트로 올린다. Actions 탭에서 수동 실행(workflow_dispatch)
하거나, `android/`·`js/`·`css/`·`index.html`을 건드리는 푸시마다 자동으로 돈다.
빌드가 끝나면 실행 페이지 하단에서 APK를 내려받아 기기에 설치하면 된다.

**로컬에서 빌드**

Android SDK(플랫폼 34)와 JDK 17이 필요하다.

```bash
cd android
gradle assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

앱은 가로 고정 전체화면 WebView로 뜨고, 진행도는 WebView의 localStorage에 저장된다.
네트워크 없이 완전히 오프라인으로 동작한다. 뒤로 가기 버튼은 이전 화면으로 가고,
타이틀에서 한 번 더 누르면 앱이 닫힌다.

## 개발 도구

빌드는 없지만 검사 도구는 있다. `npm test` 하나로 전부 돈다.

```bash
npm run lint      # 모든 js 문법 검사
npm run assets    # 참조 파일, 오프라인 캐시 목록, 데이터 정합성, 그리기 코드 유무
npm run balance   # 20개 전장 자동 전투로 난이도 곡선 검사
npm test          # 위 셋을 한 번에

npm run sim 2 3   # 병영 강화 2 / 병종 레벨 3 으로 20전장 결과표 출력
node tools/sim.js --trace 20 5 8   # 한 전장을 20초 간격으로 전황까지 찍어 본다
node tools/sim.js --gacha 3 5     # 전장 편성 vs 최상급 소환 편성을 나란히 비교
npm run smoke     # 실제 브라우저로 전 화면 + 전투 한 바퀴 (playwright 필요)
```

`tools/sim.js`는 난수를 고정해 돌리므로 같은 입력이면 항상 같은 결과가 나온다.
밸런스를 건드린 뒤 `npm run balance`가 통과하는지 보면 곡선이 깨졌는지 바로 알 수 있다.

| 성장 수준 | 기대 클리어 |
|---|---|
| 강화 0 / 병종 Lv1 | 2 ~ 8 전장 |
| 강화 2 / 병종 Lv3 | 9 ~ 15 전장 |
| 강화 3 / 병종 Lv5 | 13 ~ 18 전장 |
| 강화 5 / 병종 Lv8 | 20 전장 전부 |

여기에 더해 **소환 편성 격차**도 함께 본다. 최상급 소환 병종만 편성했을 때의 클리어
수가 전장 병종 편성과 ±4 전장을 넘게 벌어지면 실패다. 뽑기가 진도를 건너뛰는
열쇠가 되지 않도록 잡아 두는 장치다.

`tools/smoke.js`는 세 가지 가로 해상도에서 타이틀, 진군도, 병영, 훈련소, 소환,
전투를 차례로 거치며 콘솔 오류가 하나라도 나면 실패한다.
GitHub Actions의 `검사` 워크플로가 푸시마다 이 둘을 모두 돌린다.

## 구조

```
index.html        화면 마크업 (타이틀/진군도/병영/훈련소/소환의 제단/전투/회전 안내)
css/style.css     양피지 + 강철 톤의 가로 화면 UI
js/audio.js       WebAudio 로 즉석 합성하는 효과음 (음원 파일 없음)
js/data.js        병종·적·전장·강화·시즌 데이터 (밸런스와 능력치는 전부 여기)
js/game.js        전투 엔진 (이동, 타겟팅, 넉백, 상태이상, 능력, 승패)
js/render.js      캔버스 렌더러 (졸라맨 드로잉, 배경, 성채, 이펙트, 미니맵)
js/main.js        화면 전환, 저장/불러오기, 편성, 소환 로직, 타이틀 연출, 메인 루프
sw.js             오프라인 캐시
android/          WebView 래퍼 (APK 빌드용)
tools/            밸런스 시뮬레이터, 정적 점검, 브라우저 스모크 테스트
.github/workflows/android.yml   APK 빌드 파이프라인
.github/workflows/check.yml     문법·정적·밸런스·스모크 검사
```

캐릭터는 `js/render.js`의 `drawBody`에서 그린다. `legs` / `torso` / `arm` / `head`
부품을 조합하고 투구 종류와 무기만 바꾸면 새 병종이 하나 늘어난다.
시즌 병종을 추가하려면 `js/data.js`의 `SEASON_UNITS`에 `season`과 `rarity`를 넣어 정의하고
`SEASONS`의 해당 배너 목록에 id 를 넣으면 소환 풀에 바로 들어간다.
능력은 `js/data.js`의 `ab` 필드에 선언하면 엔진이 알아서 처리한다
(`heal`, `poison`, `burn`, `slow`, `stun`, `haste`, `enrage`, `crit`, `lifesteal`,
`pierce`, `barrier`, `summon`, `gold`, `kbImmune`, `deathBomb`, `revive`, `push`,
`hold`, `noAttack`, `armor`).
보스 패턴은 `phases`(체력 구간마다 한 번)와 `special`(주기 반복)에 적어 두면 된다.
기술 종류는 `roar`, `enrage`, `summon`, `shield`, `heal`, `frost`, `drain`, `meteor` 가 있고
엔진의 `bossAct` 하나가 아군·적군 가릴 것 없이 같은 코드로 처리한다.

## 필살 연출

병종마다 공격 연출이 다르다. 특히 **전설 등급**은 화면 섬광과 진동까지 따라온다.

| 연출 | 병종 |
|---|---|
| 하늘에서 내리꽂는 번개 | 제우스 |
| 대지를 흔드는 충격파 | 토르, 투석기, 강철 거인 |
| 솟구치는 빛기둥 | 아누비스, 사령술사 |
| 회전하는 마법진 | 대마법사 |
| 치솟는 불길 | 불꽃술사, 라의 사제, 화약병 |
| 얼음 파편 | 서리 마도사, 메두사 |
| 교차 참격 | 기사, 결투가, 광전사, 아레스, 펜리르, 쌍검 도적 |
| 성스러운 빛 | 성기사, 발키리, 아르테미스, 석궁 저격수 |

영웅과 전설 병종은 발밑에 등급 색 오라가 맴돈다.

연출이 한꺼번에 몰리면 프레임이 떨어지므로, 동시에 터지는 필살 연출은 4개
(전설 대형 연출은 2개)까지만 살려 둔다. 그 위로 렌더러가 **프레임 시간을 지켜보며
이펙트 품질을 스스로 낮춘다** — 26ms를 넘기면 가장 비싼 `shadowBlur` 광채부터
끄고 파티클 수를 줄이며, 다시 여유가 생기면 원래대로 돌아온다. 저사양 기기에서
연출이 살짝 단순해지는 대신 끊기지 않는다.

## 연출

- 무릎이 접히는 걷기, 반대쪽 팔 흔들기, 멈춰 있을 때의 숨쉬기
- 휘두를 때 앞으로 파고들었다 되돌아오는 반동과 무기 궤적
- 쓰러질 때 옆으로 넘어지며 사라지는 사망 연출
- 떠오르는 피해 숫자, 치명타 표시, 상태이상 아이콘, 보호막 링
- 보스 등장 경보와 상단 보스 체력바, 타격에 따른 화면 흔들림
- 보스 기술 이름 배너, 낙하 공격 예고 원, 광폭화한 보스의 붉은 기운
- 빠른 병종의 발밑 먼지, 왕의 명령 배너
- 효과음은 파일 없이 WebAudio 로 합성한다. 타이틀에서 끄고 켤 수 있다
