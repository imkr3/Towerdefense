# ⚔️ 막대 왕국 전쟁 (Stick Kingdom War)

모바일 브라우저에서 바로 즐기는 중세 라인 배틀 타워디펜스. **가로 화면 전용**이다.
캐릭터는 전부 **졸라맨**이고, 투구·방패·도끼·망토로 병종을 구분한다.
왕국군과 오크 군단이 한 줄로 붙는다. 설치도 빌드도 없다. `index.html`을 열면 끝.

세로로 들면 회전 안내가 뜬다. 타이틀의 "전체화면 · 가로 고정" 버튼을 누르면
지원 기기에서 전체화면과 가로 고정을 함께 건다.

## 플레이 방법

1. 군자금은 시간이 지나면 저절로 찬다.
2. 화면 아래 카드를 눌러 병사를 출진시킨다. 카드마다 비용과 재정비 시간이 있다.
3. 병사는 알아서 전진해 싸운다. **적 요새를 무너뜨리면 승리**, 아군 성채가 무너지면 패배.
4. 화면을 좌우로 밀어 전장을 살피고, 우측 상단 버튼으로 2배속을 켠다.
5. 전투로 얻은 골드로 병영에서 무기·갑옷·성벽·세수를 강화한다.
6. 훈련소에서 병종을 하나씩 레벨업한다. 레벨당 체력과 공격력이 10%씩 오른다.

## 콘텐츠

- **20개 전장.** 앞 전장을 돌파해야 다음이 열린다. 5 / 10 / 15 / 20은 보스전.
- **왕국군 8종** — 창병, 방패병, 궁수, 광전사, 화약병, 기사, 투석기, 대마법사.
  전장을 돌파할수록 순차 합류한다.
- **오크 군단 10종** — 고블린 졸개, 오크 창병, 오우거, 늑대 기수, 석궁 사수,
  화약통 고블린, 흑기사, 트롤 대장, 리치, 오크 대군주.
- **병종 레벨업.** 병종마다 개별 레벨을 올린다. 레벨당 체력·공격력 +10%,
  최대 15레벨. 레벨 상한은 `5 + 돌파한 전장 수`라서 진도 없이 한 병종만
  키워 밀어붙일 수는 없다. 훈련비는 병종의 출진 비용에 비례한다.
- **병영 강화 5종**, 각 10레벨. 군자금 한도, 세수, 무기, 갑옷, 성벽.
- 진행 상황은 브라우저 `localStorage`에 저장된다.

## 전투 규칙

- 병사는 사거리 안의 가장 가까운 적을 친다. 적이 없으면 전진한다.
- 체력이 일정 구간씩 깎일 때마다 **넉백**되어 뒤로 밀린다. 전선이 계속 밀고 밀린다.
- 범위 공격은 착탄 지점 주변 전부를 때린다. 투석기와 대마법사가 대표적이다.
- 근접/원거리, 이동 속도, 재정비 시간의 조합으로 전선 구성이 갈린다.

## 난이도

아무 강화도 없이 6전장까지, 병영 강화 2~3레벨이면 19전장까지 간다.
마지막 오크 대군주는 병영 강화와 병종 레벨을 함께 올려야 넘어선다.
20개 전장 전부 시뮬레이션으로 확인했고, 한 판은 60초에서 200초 사이다.
전 병종을 15레벨까지 올리는 데 드는 총 훈련비는 약 7만 골드다.

## 실행

```bash
# 그냥 파일로 열기
open index.html

# 또는 로컬 서버 (PWA / 오프라인 캐시까지 확인하려면 이쪽)
python3 -m http.server 8000
```

https 로 배포하면 `manifest.json` + `sw.js` 덕분에 홈 화면에 설치해
오프라인으로도 플레이할 수 있다.

## 구조

```
index.html        화면 마크업 (타이틀/진군도/병영/훈련소/전투/회전 안내)
css/style.css     양피지 + 강철 톤의 가로 화면 UI
js/data.js        병종·적·전장·강화 데이터 (밸런스는 전부 여기)
js/game.js        전투 엔진 (이동, 타겟팅, 넉백, 범위 피해, 승패)
js/render.js      캔버스 렌더러 (졸라맨 드로잉, 배경, 성채, 이펙트, 미니맵)
js/main.js        화면 전환, 저장/불러오기, 메인 루프, 입력
sw.js             오프라인 캐시
```

캐릭터는 이미지 파일 없이 `js/render.js`의 `drawBody`에서 선과 도형으로 그린다.
`legs` / `torso` / `arm` / `head` 부품을 조합하고 투구 종류와 무기만 바꾸면
새 병종이 하나 늘어난다. 밸런스는 `js/data.js`의 `UNITS`, `ENEMIES`, `STAGES`만 보면 된다.
